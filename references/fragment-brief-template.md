# 片段翻译任务说明（brief）模板

给每个翻译执行者（子代理或主会话自身）派发片段时，按本模板填写。方括号
`[...]` 为占位符。派发给子代理时，把整段文本作为 prompt 主体，并要求执行者
**首先用 Read 工具阅读 brief 文件**。

---

```markdown
你是《[书名]》（[作者]）中文版的翻译执行者，负责第 [N] 章的片段 [X]。
这是纯翻译 + LaTeX 转写任务，需要写文件。

【第一步——必读】用 Read 工具阅读工作说明（术语、宏、格式规则都在里面，
必须严格遵守）：
[<_BRIEF_chN.md 的绝对路径>]

【你的任务范围】
- 源 PDF：[<N章.pdf 绝对路径>]（页码换算：原书页 = PDF 页 + [offset]）
- 页面图片（300dpi）：[<pages 目录>] 中的 p[起始].png 到 p[结束].png
- 文字层摘录：[<ch_text_*.txt 路径>]（覆盖 PDF 页 [a–b]；散文底本可信，
  公式是乱码，绝不可用于公式）
- 内容：[节标题中英对照 + 覆盖的公式编号范围，如 "4.3 节 LDA 完整，
  式 (4.86)–(4.127)，共 42 条编号公式"]
- 输出文件：[<_frag_N_X.tex 绝对路径>]（太长可分 _p1/_p2 并报告）

【边界（严格遵守，避免与相邻片段重复/遗漏）】
- 开始于 [PDF 页 X] 的 [节标题/某式的后一句]：[标题的统一译名]。
  [该页顶部属于上一片段的内容（具体列出），不要翻译。]
- 结束于 [PDF 页 Y]：[某式/某句（含）]。[下一节标题及以后归别的片段。]
- [该范围内需要特别注意的脚注/跨页公式/图表，逐条列出归属]

【必须包含的结构】
1. [节/小节标题（用 brief 统一译名表中的中文）]
2. 编号公式 [(N.a)–(N.b)]，共 [K] 条，顺序连续无缺，无 \tag。
3. [图 N.x（PDF 页 x/原书页 y）：用 brief 的「待插入插图」模板，
   图注完整翻译，\label{fig:N.x}]
4. [表 N.y（PDF 页 z，是否跨页）：数字逐格对照图片核对]

【方法（严格遵守）】
1. 先读文字层了解散文；
2. 用 Read 工具逐页读图片，每一条公式（含行内公式）以图片为准转写 LaTeX；
   文字层公式是乱码，绝不可用；
3. 疑难公式（上下标/撇号/指数/求和下标）用裁剪放大脚本核实：
   python <skill>/scripts/crop_zoom.py <pdf> <out.png> <页> <y0> <y1> 10
   （Python: [venv python 绝对路径]）
4. 用 Write 工具写片段文件；
5. 自查：\begin{equation}+multline 计数恰好 [K] 个、顺序 (N.a)→(N.b)、
   无 \tag、label eq:N.a–eq:N.b 唯一。存疑处写 % 【存疑】注释。

【完成后报告】（[字数] 内）
处理的页范围、编号公式个数核对结果、图表处理方式、任何存疑清单
（片段内用 % 【存疑】注释标明位置）。
```

## 视觉复核任务模板（用于校对已完成的片段）

```markdown
你是《[书名]》中文版的校对执行者。片段 [X]（[输出文件路径]）已由他人完成，
必须逐条视觉复核并修正。

【必读】工作说明：[<_BRIEF_chN.md>]；覆盖 PDF 页 [a–b]，页面图片 [pages 目录]。

【工作内容】
1. 逐页 Read 图片，将片段中每条公式（编号的 + 无编号的 + 行内公式）与图片
   逐一比对：上下标、撇号、矢量粗体、正体/斜体、积分/求和范围、指数、括号
   分组、求和下标个数。
2. 发现错误用 Edit 直接改正（对同一文件的编辑必须串行执行），并加注释
   % 【修正标记】原表述：… → 问题：… → 现表述：…
3. 表格数字逐格核对；图浮动体模板合规性检查。
4. 不改正确内容；不改结构、标题、编号体系；不用 \tag。
5. 疑难符号用 crop_zoom.py 放大核实。

【完成后报告】核对数量；修正错误数与逐条清单；遗留存疑（保留 % 【存疑】）。
```
